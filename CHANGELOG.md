# Changelog

## 1.0.0

- Show Codex five-hour and weekly usage in the SwiftBar menu bar.
- Display remaining capacity, progress bars, local reset times, and account plan.
- Refresh every minute and provide a manual refresh option.
- Use green, amber, or red indicators according to usage.
- Fall back to cached data up to 24 hours old when a request fails, with an amber indicator and a warning symbol.
