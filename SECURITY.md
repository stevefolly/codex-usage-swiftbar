# Security

## Reporting a vulnerability

- **GitHub:** If private vulnerability reporting is enabled, use **Security → Report a vulnerability** to send details privately.
- **GitLab:** If you can create a confidential issue, mark it confidential before submitting any security details. See [GitLab's confidential issue guidance](https://docs.gitlab.com/user/project/issues/confidential_issues/).

If the private reporting option on your platform is unavailable, open an issue asking the maintainer for a private reporting channel. Keep that initial issue free of exploit details, credentials, and personal information.

In a private report, include the affected version, the potential impact, and steps to reproduce the problem using dummy data where possible. Never send real account credentials or authentication files.

## Scope

Reports about this plugin's handling of local processes, cache files, and displayed data are welcome. Issues in Codex or SwiftBar itself should be reported to the relevant project.
